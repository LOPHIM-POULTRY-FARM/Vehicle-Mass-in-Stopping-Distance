# Stopping Distance Traffic Model

## Overview
This project simulates vehicle stopping distance using a multi-factor model incorporating:
- Vehicle mass
- Reaction time (day/night)
- Brake delay (by vehicle category)
- Road friction (dry vs wet conditions)

## Model Features
- Multi-class vehicle system
- Physics-based braking model
- Weather condition simulation
- Night vs day reaction time modelling
- Python-based computational implementation
